SOURCE SNAPSHOT HARDENING (THIS BUILD)
Every vNext CLI materialization requires --source-manifest.
- A second local frozen snapshot must exist at snapshot_filename relative to
  the manifest's directory and must be a DIFFERENT file from input.
- SHA-256, byte sizes, and input record count must match.
- The transformation policy must be BYTE_IDENTICAL. No implicit geocoding,
  reprojection, clipping, geometry repair, or source identity inference.
- JSON parsing rejects duplicate keys, NaN and Infinity.
- source_authority_evidence_state must be UNVERIFIED; this manifest is not
  a certification of source authority or raw coordinate provenance.
- Source_Provenance_State = BYTE_VERIFIED_AUTHORITY_UNRESOLVED.
- Source_Manifest_SHA256 is the hash of the raw manifest bytes.
- If manifest, input, or frozen snapshot changes, generate a NEW versioned
  snapshot and receipt; never overwrite old manifests to simulate prior state.
- Abort before writing either output when any source/row/hash gate fails.
- Recheck receipt output hash after run and before downstream reads.

LINE LENGTH SEMANTICS (THIS BUILD)
Clipped_Traversal_Length_m measures traversed length including repeated passes.
Distinct_Clipped_Spatial_Support_Length_m dissolves overlapping source
segments and measures unique geometric support (not number of visits).
Retraversed_Spatial_Length_m = traversed length - distinct support length.
Cell_Bound_Length_Sum_m sums all qualifying per-cell line segments.
Grid_Edge_Length_Multiplicity_m = cell-bound sum - traversed length;
it measures multiple cell assignments due to shared grid boundaries,
NOT repeated source traversals. Never interpret either as feature identity.
