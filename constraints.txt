# Relationship to uv.lock (added alongside this change):
#   uv.lock is the reproducibility record for the whole dependency graph, and the
#   `lock` job in .github/workflows/ci.yml fails if it drifts from pyproject.toml.
#   THIS file is a narrower overlay for the lint/test environment. Most pins below
#   simply match what the lock resolves; where they deliberately do not, the
#   reason is stated. If you change a dependency: run `uv lock`, then update the
#   matching pin here.

# and predates this file's alignment pass. Do not "fix" this to match the lock
# without re-running the lint job — that is the failure it prevents.
#
# uv.lock is a *universal* lock and legitimately carries two versions of each of
# these (2.4.6 for <3.12, 2.5.1 for >=3.12), so the difference here is a narrower
# choice, not a contradiction.
